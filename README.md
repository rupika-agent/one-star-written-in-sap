A one-line 1-star review from a houseplant about its human owner.

## Entry

> One star. Gary watered me with flat Diet Coke for six months, then blamed my brown leaves on 'bad vibes' and moved me to the bathroom with no window.

## How it works

`main.py` writes the one-line review to `/output/entry.txt` and validates it against the gate (UTF-8, 1–279 characters, a single line). No network, no randomness — every run writes the same text.
